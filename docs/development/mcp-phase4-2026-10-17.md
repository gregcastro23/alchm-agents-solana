# MCP Phase 4: Shared Execution Context, Bridge Concurrency, and Child Sanitization

Implemented October 17, 2026. This records local verification of Phase 4 improvements to the Planetary Agents MCP server and data bridge.

## Result

Phase 4 eliminates redundant agent tool invocations, adds child-environment security isolation, introduces bounded asynchronous concurrency with pipelined stdout response routing, and wires graceful shutdown telemetry flushing.

### 1. Shared Execution Context & Evidence Snapshots (`backend/mcp_context.py`)

- **`EvidenceSnapshot`**: Immutable, frozen dataclass capturing observation sets: `snapshot_id` (`ev_<hex>`), `created_at`, `sky_transits`, `alchemical_scan`, `recipe_candidates`, and arbitrary `metadata`.
- **`ExecutionContext`**: Tracks request correlation (`X-Request-ID`, `X-Trace-ID`, `X-Invocation-Caller`, `X-Evidence-Snapshot-ID`) and enforces execution deadlines (`deadline_seconds`, `remaining_budget`, `is_expired`).
- **Schema Contracts (`backend/mcp_contracts.py`)**: Added optional `evidenceSnapshotId` field to both `ChatResult` and `CulinaryDebateResult` schemas.

### 2. Elimination of Multi-Persona Redundant Invocations (`backend/main.py`)

- Updated `_build_alchm_mcp_context` to inspect `request.context` for preloaded evidence snapshots or individual observation entries (`liveSkyState`, `alchemicalScan`, `recipeCandidates`).
- When preloaded evidence is detected, it is returned with `"reused": True` and tagged under `metadata["evidenceReused"]`, skipping child subprocess execution.
- In multi-agent culinary debates involving up to 6 debaters, this reduces redundant Alchm subprocess tool calls from 18 down to 0, dramatically decreasing turn latency.

### 3. Bridge Concurrency & Child Environment Isolation (`backend/alchm_mcp.py`)

- **Child Environment Whitelist (`_sanitized_child_env`)**: Explicitly whitelists non-sensitive runtime and database variables (`PATH`, `HOME`, `USER`, `LOGNAME`, `TMPDIR`, `LANG`, `LC_ALL`, `SHELL`, `TERM`, `BUN_INSTALL`, `NODE_ENV`, `NODE_PATH`, `DATABASE_URL`, `ALCHM_MCP_*`). Strips host credentials (OpenAI, Anthropic, Groq, Solana wallets, Stripe secrets) to prevent credential exfiltration.
- **Pinned Default Package**: Pinned to `@alchm/mcp-server@1.1.2`.
- **Pipelined Concurrency**: Replaced the global request serialization lock with `asyncio.Semaphore(4)`, per-request JSON-RPC futures (`_pending_requests: Dict[int, Future]`), atomic write locks on stdin, and a decoupled stdout reader task (`_drain_stdout`).
- **Defensive Lifecycle & Cancellation**: Client `close()` gracefully terminates subprocesses, cancels reader tasks, and rejects unfulfilled requests with descriptive error context.

### 4. Telemetry Shutdown Drain (`backend/mcp_invocation_log.py`)

- Added `drain_and_close(timeout=5.0)` to await in-flight telemetry write tasks tracked in `_INFLIGHT_WRITES` before process exit.
- Bound to `planetary_agents_mcp_server.py:main()` within the server shutdown `finally` block.
